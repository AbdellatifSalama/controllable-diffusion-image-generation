# Dataset instructions

Place training images in `data/images/` and create `metadata.csv` with columns:

- `file_name`: image filename relative to the image directory
- `text`: accurate caption describing architectural style, materials, geometry, viewpoint, and lighting

Use a dataset whose license explicitly permits the intended research use and comply with attribution/redistribution conditions. Keep a `SOURCES.md` recording dataset name, URL, license, access date, and any preprocessing. Do not commit the dataset unless redistribution is permitted.
